Acesso ao painel

O acesso ao painel é controlado pelo banco de dados (Supabase), em Authentication › Users. Nenhuma senha fica gravada no site nem no navegador.

  • Para dar acesso a alguém: crie o usuário com e-mail e senha e marque como confirmado.
  • Para tirar o acesso: exclua o usuário. O efeito é imediato.
  • Para trocar a senha: use "Reset password" no próprio usuário.

Ao sair do painel, o navegador apaga os dados de clientes guardados em cache. Em computador compartilhado, sempre use o botão SAIR.
